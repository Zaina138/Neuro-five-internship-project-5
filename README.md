🌤️ Velora Weather Dashboard

A modern and elegant weather dashboard built with HTML, CSS, and JavaScript. Velora provides real-time weather information with a clean, responsive interface and a soft cream and burgundy aesthetic.

✨ Features

- 🔍 Search weather by city
- 📍 Get weather using your current location
- 🌡️ Current temperature
- 🌤️ Weather condition and weather icons
- 💧 Humidity information
- 〰️ Wind speed
- ☔ Rain probability
- 🌡️ Atmospheric pressure
- 🌅 Sunrise and sunset times
- 📅 7-day weather forecast
- 📱 Fully responsive design
- ✨ Smooth animations and hover effects
- ⚠️ User-friendly loading and error states
- 🔑 No API key required

🎨 Design

Velora uses a soft, premium-inspired visual style:

- Background: Warm Cream "#F3EEE6"
- Primary: Deep Burgundy "#581000"
- Typography: Playfair Display + DM Sans
- Style: Minimal, elegant, glassmorphism-inspired cards

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Geolocation API
- Open-Meteo Weather API
- Google Fonts

🌐 API

Weather data is provided by Open-Meteo.

The project uses Open-Meteo's:

- Geocoding API for searching cities
- Forecast API for current weather and forecasts

No API key or account is required.

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure the following files are present:
   - "index.html"
   - "style.css"
   - "script.js"
4. Open "index.html" using Live Server.
5. Search for any city and explore its weather.

📱 Responsive Design
Velora is designed to work across:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📟 Tablet

The layout automatically adapts to smaller screens using CSS media queries.
